# Задачи проекта En Ru Switcher

## Оформление

1. Документация ведётся в doc/**.md
2. Файлы для публикаций в aur, flatpack и т.д. в packaging/
3. Модули проекта в src/
4. Юнит-тесты в tests/unit/
5. Функциональные в tests/functional
6. Статус и правила пакетов — doc/packaging.md

## Задачи

* [x] Юнит-тесты на фреймворке Check для Pure functions с libbacktrace
* [x] Функциональные тесты для окна конфига на tcl+tk. С tcltest и `event generate .top.entry_field <Motion> -x 10 -y 10`
* [x] Разбить монолит в src/ по doc/arch.md
* [x] Добавить команду check-deps в make
* [x] Юнит-тесты перенести на фреймворк Criterion (колоризация) с `CFLAGS += -fsanitize=address -g` и `LDFLAGS += -fsanitize=address` (для стектрейса вместо libbacktrace, проверить, что поддерживается gcc и clang)
* [x] Добавить покрытие утилитами gcov, lcov или gcovr. Предусмотреть отчёт: `gcovr -r . --html --html-details -o coverage.html` и вывод на консоль `gcovr -r . --txt-metric branch` в виде команд make
* [x] Динамический анализ (санитайзеры) и фаззинг-тесты / doc/test-metodology.md
* [x] Добавить Clang-Format для форматирования кода, отформатировать код. Убрать astyle
* [x] Добавить чекер cppcheck и CFLAGS += -fanalyzer, чекнуть код
* [ ] Добавить юнит-тесты, функциональные (если xorg-server-xvfb можно установить), покрытие, линтер и форматтер в github CI. Отладить `.github/workflows/test.yml`. Запуск локально `act -j test-linux`. См. https://github.com/actions/runner-images, https://github.com/cross-platform-actions/action
* [x] ERSWITCHER_DEBUG=1 – включает вывод отладки и нажатых комбинаций клавишь на консоль. Сейчас выдаётся постоянно. Добавить временные метки, чтобы можно было посчитать время между событиями
* [x] Переключение языков по комбинации клавишь (функция в конфиге разделе [options] – switch_language = OSSwitchLanguage|Caps_Lock). Сейчас – переключение через X11 (для неё оставить эту функцию как виртуальную клавишу "OSSwitchLanguage"). Это для окон виртуальных машин – эмуляция комбинаций клавиш сможет переключить язык ОС
* [ ] Добавить инфраструктуру Wayland
* [ ] Добавить в конфигуратор панель с поиском и заменой. В /ext/__/ninja/lib/Ninja/tk/main-window.tcl есть готовый `#@category диалог поиска`. Нужно его взять оттуда, но для операций поиска и замены использовать средства tcl (в том числе для регулярок). Формат замены: $1, $2, $3 – группы из регулярки
* [ ] Сниппеты в файлах. Сейчас сниппеты однострочные, нужно внутрь однострочных сниппетов вкладывать \{^snip-name\}. Сниппеты будут хранится в ~/.config/erswitcher/snippet/*.snip. Перенести в ~/.config/erswitcher так же erswitcher.conf и erswitcher-configurator.conf. Секции [snippets], [compose], [sendkeys]
* [ ] В сниппетах можно вводить \{ Cotrol+Alt+F1 \}. Секции [snippets], [sendkeys]
* [ ] В сниппетах можно использовать команды \{ cat file \}. Вывод команды в stderr появляется в "Уведомлениях рабочего стола", а stdout – вставляется в текст выдаваемый сниппетом. Секции [snippets], [compose], [sendkeys]
* [ ] Если пользователь нажал Esc, когда erswitcher вводит с клавиатуры, то ввод останавливается. Секции [snippets], [sendkeys]
