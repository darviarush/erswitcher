# Архитектура erswitcher

## Структура файлов

```
erswitcher/
├── doc/                        # Документация и скриншоты
├── tests/                      # Модульные тесты (Check Framework)
│   └── unit/
│       ├── test_translit.c     # Тесты алгоритмов перевода букв
│       └── test_buffer.c       # Тесты кольцевого буфера ввода
│
├── src/
│   ├── domain/                 # 1. СЛОЙ ДОМЕНА (Бизнес-правила)
│   │   ├── translit.c          # Чистая функция: "ghbdtn" -> "привет"
│   │   ├── translit.h
│   │   ├── case_invert.c       # Чистая функция: инверсия регистра ("Привет" -> "пРИВЕТ")
│   │   └── case_invert.h
│   │
│   ├── use_cases/              # 2. СЛОЙ ПРИЛОЖЕНИЯ (Сценарии использования)
│   │   ├── input_buffer.c      # Кольцевой буфер (хранит историю нажатий, умеет стирать слово)
│   │   ├── input_buffer.h
│   │   ├── config_parser.c     # Разбор конфига erswitcher.conf в структуры Си
│   │   ├── config_parser.h
│   │   └── interfaces/         # Порты (Интерфейсы взаимодействия с ОС)
│   │       ├── os_keyboard.h   # Описание функций: "эмулировать нажатие Backspace", "ввести символ"
│   │       ├── os_clipboard.h  # Описание функций: "взять из буфера", "записать в буфер"
│   │       └── ui_tray.h       # Описание функций: "обновить иконку в трее"
│   │
│   ├── infrastructure/         # 3. ИНФРАСТРУКТУРА (Реализация портов под X11 / OS)
│   │   ├── x11/
│   │   │   ├── x11_keyboard.c  # Реализация os_keyboard.h через libXtst.so / XTestFakeKeyEvent
│   │   │   ├── x11_clipboard.c # Реализация os_clipboard.h (работа со свойствами X11 SELECTION)
│   │   │   └── x11_events.c    # Поток прослушивания xkbcommon событий
│   │   └── system/
│   │       └── exec_command.c  # Запуск шелл-скриптов из секции [commands] (через fork/exec)
│   │
│   └── presentation/           # 4. СЛОЙ ПРЕДСТАВЛЕНИЯ (Интерфейс)
│       └── tray_indicator.c    # Отрисовка значка в трее (красный квадрат)
│
├── main.c                      # Точка входа (собирает зависимости, запускает цикл X11 событий)
├── erswitcher.conf             # Конфиг по умолчанию
└── Makefile                    # Скрипт сборки
```

## Преимущества

1. Тестируемость (src/domain и src/use_cases):
	Не нужно инициализировать тяжелый дисплей X11 (XOpenDisplay), чтобы проверить, правильно ли работает алгоритм замены символов или сохранение сниппетов
2. Изоляция Use Cases:
	Модуль input_buffer.c управляет логикой: "когда нажат пробел — сбросить буфер, когда нажата стрелка — забыть ввод, когда нажата Pause — отдать последнее слово на транслитерацию". Он работает на уровне абстрактных событий и ничего не знает про **X11**
3. Заменяемость инфраструктуры:
Если будет решено поддержать **Wayland** (где библиотеки **X11** не работают) – чистая архитектура спасет проект. Папки domain, use_cases и presentation останутся нетронутыми. Нужно будет лишь создать папку `src/infrastructure/wayland/` и написать там альтернативную реализацию для `os_keyboard.h`
